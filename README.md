# 背景プロンプト工房

AI画像生成向けの背景を日本語UIで構造的に設計し、生成先に合わせた英語プロンプトへ変換するWebアプリです。

GitHub Pages: <https://nyuriwossan.github.io/background-prompt-workshop/>

## 主な機能

- 空間背景／シンプル背景の2モード
- 4ステップの画面：どんな場所？ → どう見える？ → 細かく仕上げる → 生成先を選んでコピー
- 場所の日本語検索（ひらがな・別名でも探せます）
- **見え方の設計**：どこから見るか・何が見えるか・視線の向き・距離・高度・動き・手前の枠・画角を、場所とは別に指定
  - 成立しない組み合わせは押せなくし、理由を日本語で表示
  - 今の設定で使えなくなった値は、保存したまま出力からだけ外す
- **生成先の切り替え**：汎用（従来どおり）／PIXAI Tsubaki系（自然文）／PIXAIタグ系／NovelAI
  - 短縮版・詳細版と自由に組み合わせ可能
  - ネガティブ・Undesired Contentは、対応する生成先・モードのときだけ作成
  - NovelAIの数値強調は任意（見え方の句だけ）
- **動きのある見え方**：飛行・滑空・急上昇・雲を抜けて降下・急降下・落下・高速で横を通過。移動の向きと遠近の手がかりを先に書き、人物の姿勢と読まれやすい語（falling など）は使いません
- **やり直し**：「選択をクリア」（場所・生成先などは残し、任意の選択をすべて外す）と「初期設定に戻す」（作例の状態に戻す）
- **季節・イベント装飾（シンプル背景）**：桜・新緑・入学卒業・ホワイトデー・七夕・夏祭り・紅葉・お月見・ハロウィン・冬・クリスマス・お正月・バレンタイン・誕生日、海外の行事（イースター・春節・ディワリ・プライド月間）の18テーマ
  - **イベント**（何の行事か）と**テイスト**（どういう見た目か・16種）を分けて選べます。同じクリスマスでもクラシック・ゆめかわ・ダークかわいいなどに展開できます
  - イベントを選ぶと、その行事らしいモチーフを1〜2種類、端か上側に「まばら」で入れます。人物の顔・衣装の周りは空けます
  - 既存の9モチーフは複製せずに再利用し、識別しやすい季節モチーフを32件追加（`app/lib/seasonal-data.ts`）
  - 見分けにくい組み合わせ・別の文化の飾りの混在・文字が入りやすいモチーフは、アドバイスで知らせます
  - イベントもテイストも選ばないときの出力は、v2.1と1文字も変わりません
  - **人物と装飾を分ける（v2.3）**：かぼちゃ・キャンドル・短冊など人物に混ざりやすいモチーフは、人物を描く設定のとき「背景のフチの小さな平面装飾」として書きます（オン・オフ可。混ざりやすいモチーフを選んだときだけ表示）。背景だけで使うときは、人物に関する文を出しません
  - **試験機能（v2.4）**：季節の装飾を人物向けに使うとき、出力欄の「試験機能」で背景キーワードを5方式（A：simple background〔既定〕／B：なし／C：decorative background／D：portrait backdrop／E：simple decorative backdrop）並べて比べられます（NovelAI・PIXAIタグ系）。装飾の書き方（stickers／printed motifs／decorative illustrations）と、位置の句に border を使うかどうかも切り替えられます。既定の出力は変わりません
  - **検証メモ**：1枚ごとに生成先・方式・人物指定・seed と6項目の評価を端末内に記録し、条件ごとに集計・CSV書き出しできます（設計の保存一覧とは別）。v2.5で「人物指定の入力先」（通常の欄にまとめた／キャラクター欄に分けた／不明）を追加。v2.4の記録は「不明」として読み込みます
  - **NovelAIの組み合わせ方（v2.5）**：季節の装飾を人物向けに使うとき、人物の指定をキャラクタープロンプト欄、工房の出力をベースプロンプトに分ける方法を案内します（実画像での傾向で、成功を保証するものではありません）。工房の出力に人物タグは入れません
- 人物と背景の比重、相性警告と補助提案
- プリセット（空間53件・シンプル36件〔うち季節・行事21件〕）、端末内保存、JSON入出力、コピー
- スマートフォン対応（下部にコピー・保存、出力欄へすぐ移動）

## 保存データ

保存形式は v2 です（v2.2で、シンプル背景に `eventTheme`・`designProfile` を追加。v2.3で `decorSeparation` を追加。古いデータでは、イベント・テイストは「選ばない」、分けるは「オン」で補われます）。v1 の下書き・保存一覧・書き出しJSONはそのまま読み込めます（見え方は「標準」、生成先は「汎用」として補われ、従来と同じ英文になります）。初めて v2 で開いたときは、移行前のデータを `background_prompt_workshop_backup_before_v2` に控えとして残します。JSONで保存一覧を読み込むと、今の保存に追加されます（置き換えません）。

## ローカル実行

Node.js 22以降が必要です。

```bash
npm ci
npm run dev
```

## 検証

```bash
npm test             # 生成・移行・矛盾制御の回帰テスト
npm run build
npm run build:pages
```

画面の通しテスト（Python版Playwright）：`gh-pages/` を `/background-prompt-workshop/` で配信してから

```bash
python3 tests/e2e/ui-smoke.py http://localhost:8765/background-prompt-workshop/
```

## GitHub Pages

`main` ブランチへのpushで、`.github/workflows/deploy-pages.yml` が静的ビルドを作成し、GitHub Pagesへ自動公開します。

## 季節モチーフの英語表現について

`app/lib/seasonal-data.ts` の新規モチーフは、すべて `validation: "unverified"`（PIXAI・NovelAIでの実生成は未検証）です。実画像で確かめたものから `"tested"` に書き換えてください。

人物への混入リスク（`fusion`）は仮説として登録しています。実画像で起きた事象だけ `fusion.observed` に日付と生成先を記録しています（2026-10-30 NovelAI：ジャック・オ・ランタン、キャンドル、短冊、笹、月）。
